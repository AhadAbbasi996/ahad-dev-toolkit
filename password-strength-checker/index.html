SECURITY BENCHMARKS & FAQ

What is Password Entropy?

Entropy measures unpredictable randomness in bits ($E = L \times \log_2(N)$). Every +10 bits of entropy multiplies cracking difficulty by 1,024 times.

Length vs. Complexity

A long passphrase like correct-horse-battery-staple (77 bits) is exponentially stronger than a short complex password like Tr0ub4d! (42 bits).

Rule-Based Dictionary Attacks

Attackers use Hashcat rules replacing 'a' with '@' or 'e' with '3'. Simple leetspeak offers virtually zero extra security against modern GPUs.
